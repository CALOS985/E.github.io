Release notes

本次更新：更稳妥地查询与保存

围绕频繁触发人机验证和 Excel 文件安全进行了针对性优化。

v4.0 保守稳定版 更新日期：2026-09-10 当前推荐版本
  • 保守请求节奏随机间隔 10–18 秒，每批最多处理 12 个新请求。
  • 小时级缓存只复用同一自然小时的数据，跨小时自动重新查询。
  • 主图按需下载主图列已有文字或图片时跳过，空白时才下载。
  • 风控自动停机检测到 403、429、人机验证或拦截页时立即停止。
  • Excel 安全保存先写入临时文件并校验，再替换原表，降低文件损坏风险。
  • 图片写入更稳定优化图片数据复用，避免重复保存时出现文件流错误。

Core features

为 Walmart 运营整理的实用流程

01 / EXCEL

Excel 批量处理

导入包含 Item ID 的任务表后自动逐行查询，并把库存结果写回原有表格结构。

02 / IMAGE

主图智能跳过

主图下载默认开启；已有数据或嵌入图片的单元格自动跳过，仅补齐空白位置。

03 / SAFETY

验证保护与停止按钮

出现风控信号时停止继续请求，减少连续触发验证；运行过程中也可随时手动停止。

!

运行环境与注意事项

  • 仅支持 Windows 操作系统。
  • 运行前请确保当前网络可以正常访问 Walmart 官网；请遵守网站条款并控制查询频率。
  • 软件启动前请务必关闭待处理的 Excel 文件，避免文件占用造成读写冲突。
  • 若出现 403、人机验证或拦截提示，请按软件提示停止操作，完成验证后再继续。
